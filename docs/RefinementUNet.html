1. 무엇이며 왜 필요한가

이 파이프라인의 Stage 1은 조건부 확산 모델(DAD)이다. 과거 30분 간격 위성 일사량 프레임 5장을 조건으로 미래 프레임(t+30~120분)의 조건부 분포를 학습하고, 추론 시 서로 다른 노이즈 시드로 8회 샘플링해 MC-8 앙상블을 만든다. 확산 모델의 개별 샘플은 날카롭지만, 두 가지 픽셀 수준 오차가 남는다:

  • 유한 스텝 샘플링 오차 — DDIM 40스텝 근사와 확률적 샘플링 자체의 분산.
  • 앙상블 평균의 블러 — 8개 멤버를 픽셀 평균하면 MSE는 좋아지지만, 멤버마다 위치가 조금씩 다른 구름 경계가 상쇄되어 고주파 디테일이 뭉개진다(스펙트럼 평균화). FID·LPIPS가 나빠지는 원인.

RefinementUNet은 이 오차를 사후에 고치는 Stage 2다. 핵심 아이디어는 이미지를 다시 그리지 않고, 정답과 베이스 예측의 차이(잔차) r = x − ŷ 만을 작은 확산 모델로 학습·샘플링해 ŷ에 더하는 것이다. Stage 1은 완전히 동결되며, 두 단계는 파일(예측 덤프)로만 연결된다.

한 문장 요약

동결된 확산 예보기의 출력 ŷ 위에서, 그 예보기의 조건부 오차 분포 p(r | ŷ, context)를 x0-파라미터화 확산으로 학습하고, 결정적 DDIM으로 잔차를 샘플링해 x̃ = ŷ + r̂ 로 복원하는 2.25M 파라미터의 경량 보정기.

3. 수학적 정식화

표준 DDPM 프레임워크를 "잔차"라는 신호에 적용한 것 — 수식 구조 자체는 교과서와 동일

3.1 잔차 확산의 학습 목표

GT 프레임 x, 베이스 멤버 예측 ŷ에 대해 잔차 r = x − ŷ를 확산의 "데이터"로 삼는다. 선형 스케줄의 표준 forward 과정으로 잔차에 노이즈를 입히고:

x_t = √ᾱ_t · r + √(1 − ᾱ_t) · ε,   ε ~ N(0, I),  ᾱ_t = ∏ (1 − β_s),  β: 1e-4 → 2e-2 (linear, T = 1000)

네트워크 R은 노이즈 ε이 아니라 깨끗한 잔차 r 자체를 직접 예측한다 (x0-파라미터화):

ℒ = 𝔼t, ε ‖ R(x_t, C, ŷ, t, d, h, ℓ) − r ‖²   (C: context 5장, d·h: 대상 시각의 날짜·시각, ℓ: lead 인덱스)

왜 ε-예측이 아니라 x0-예측인가. 잔차는 0 근방의 저에너지 신호라서 예측 목표의 스케일이 작고 안정적이며, 검증 지표(잔차 x0-MSE)가 곧 학습 목표가 되어 모델 선택이 단순해진다. 또 아래 DDIM 갱신식에 예측값이 그대로 대입되므로 샘플링 코드도 간결하다. SNR 가중이나 v-파라미터화 같은 장치는 사용하지 않는다 — 잔차 신호에는 순수 MSE로 충분했다.

3.2 추론: 결정적 DDIM

초기 노이즈 z에서 출발해 η=0 DDIM으로 40스텝(1000스텝을 25 간격으로 성김) 역과정을 수행한다. 매 스텝 R이 r̂₀를 예측하면:

ε̂ = ( x_t − √ᾱ_t · r̂₀ ) / √(1 − ᾱ_t)
x_{t′} = √ᾱ_{t′} · r̂₀ + √(1 − ᾱ_{t′}) · ε̂   (t′ = 다음 성긴 스텝, η = 0 → 확률항 없음)
최종 출력: x̃ = ŷ + r̂   (마지막 스텝의 r̂₀)

η=0이므로 초기 노이즈 z가 정해지면 출력이 완전히 결정된다. z는 (샘플명, 멤버 인덱스, 기준 시드 1253)에서 해시로 파생하므로, 파이프라인 전체가 재실행 시 비트 단위로 재현된다. 모델의 본성은 확률적(잔차의 분포를 학습)이지만, 운용은 결정적이다.

4. 아키텍처 해부

총 2,252,769 파라미터 (코드로 실측) · 어텐션 없음 · 체크포인트 ≈9MB

4.1 입력 구성 — 조건화는 두 갈래

  • 공간(이미지) 조건 → 채널 결합. 노이즈 낀 잔차 x_t(1ch) + context 5장 + 베이스 예측 ŷ(1ch) = 7채널을 그대로 쌓아 stem conv에 넣는다. 별도 인코더 없음. ŷ가 입력에 포함되는 것이 핵심 — "무엇을 얼마나 고칠지"는 ŷ를 봐야 알 수 있다.
  • 스칼라 조건 → 임베딩 가산. 확산 timestep t(정현파+2층 MLP), 대상 시각의 계절성(day-of-year·hour를 cos/sin 4차원으로 주기 인코딩 후 MLP), lead 인덱스(MLP)의 세 임베딩을 합산해 256차원 벡터 c 하나로 만들고, 모든 ResBlock에 주입한다.

4.2 ResBlock — DDPM 표준형 + 가산 조건

h   = Conv3×3( SiLU( GroupNorm(x) ) )
h   = h + Linear( SiLU(c) )        ← 조건 벡터를 채널별 shift로 가산 (γ 없는 FiLM, DDPM 관례)
h   = Conv3×3( SiLU( GroupNorm(h) ) )
out = h + skip(x)                   (입출력 채널이 다르면 skip = Conv1×1)

조건 주입이 채널 단위·공간 균일이라는 점에 유의 — SPADE류의 픽셀별 변조는 쓰지 않는다. 공간 정보는 전적으로 7채널 입력 결합이 담당한다.

4.3 그 외 설계 선택

  • 다운샘플 = stride-2 conv, 업샘플 = bilinear 보간 + conv. transposed conv 대신 보간+conv를 써서 격자(checkerboard) 아티팩트를 차단 — 잔차가 고주파 신호라 아티팩트에 민감하다.
  • 어텐션 없음. 잔차 보정은 국소적 과제라는 판단으로 순수 conv 구성. 이것이 2.25M 초경량의 주 요인.
  • 출력 conv zero-init. 학습 시작 시 r̂₀ ≡ 0 → x̃ = ŷ, 즉 항등 보정에서 출발. "보정기가 베이스보다 나빠질 수 없는" 하한을 학습 동역학에 내장한 장치다.

5. 학습 절차

Stage 1 동결 · 오프라인 pre-compute · 멤버 union · valid 기반 선택

  1. 오프라인 pre-compute. 동결된 Stage 1로 train/valid/test 전 분할을 미리 추론해 멤버별 덤프를 저장한다. Stage 1이 동결이므로 매 epoch 재추론과 등가이면서 E배의 중복 forward를 없앤다. 학습 중 Stage 1로의 역전파는 없다.
  2. 멤버-union 학습. train 분할의 8개 멤버 각각을 독립 학습쌍으로 사용 — 타임스탬프당 8쌍, t+1 기준 총 45,392쌍. 하나의 보정기가 "베이스가 만들 수 있는 다양한 예측"의 오차 분포를 폭넓게 본다.
  3. 모델 선택. valid 8멤버 union의 잔차 x0-MSE(= 학습 목표와 동일한 프록시)가 최저인 epoch을 best_R.pt로 선택. 매 epoch 체크포인트도 보존(개당 ≈9MB). 검증 풀은 --val_members로 학습과 독립적으로 좁힐 수 있다: first를 주면 member_0 하나로만 검증해 에폭당 검증 비용이 1/K로 준다 — val MSE는 단일 멤버의 수천 샘플 평균만으로도 안정적이어서 best 선택에 미치는 영향은 미미하다. 6. 추론과 앙상블 집계

  • 멤버별 보정 → 평균 (채택 방식). test 멤버 8개를 각각 DDIM-40으로 보정한 뒤 픽셀 평균 — 표준 명칭 "8 members refined mean". 앙상블의 다양성(확률성)은 Stage 1의 MC 샘플링이 전담하고, 보정기는 각 멤버를 같은 규칙으로 손보므로 멤버 간 분포 구조가 유지된다 → fair CRPS까지 개선.
  • 비교용 변형: 평균 선(先)보정 ("MC8 mean refined"). 멤버 평균을 1회만 보정하는 방식. 4개 지평선 전부 정확도(MSE·SSIM·CRPS) 열세, 지각 지표(FID·LPIPS)만 개선 — 채택되지 않음(9절).
  • 재현성 계약. 초기 노이즈 시드 = f(샘플명, 멤버 k, base 1253), η=0. 병렬 샤딩 시에도 같은 시드 규약을 유지해 단일 실행과 비트 동일한 출력을 보장.
  • 출력. 타임스탬프당 1장, (1,512,512), [−1,1] 정규화 .pt. 물리 단위 복원은 x_raw = (x+1)/2·(max−min)+min.

8. "디퓨전 두 개"가 아닌 이유

생성 확산 모델을 단순히 직렬로 두 번 쓰는 것과의 차별 요소 5가지

8.1 모델링 대상의 분해 — 역할이 다른 두 분포

Stage 1은 p(x | C) — 관측 조건에서 미래가 어떻게 될지의 분포 — 를 학습한다. Stage 2는 p(r | ŷ, C) — Stage 1이 만든 특정 예측의 오차가 어떤 구조인지의 분포 — 를 학습한다. 두 번째 모델은 예보 과제를 다시 푸는 것이 아니라, 첫 모델의 체계적 결함(경계 블러, 밝기 오프셋, 유한 스텝 오차)을 과제로 삼는다. 생성 확산을 두 번 직렬하면 두 번째 모델이 같은 과제를 중복 학습하게 되고, 이 분해가 사라진다.

8.2 잔차 신호의 통계적 이점 — 1/54 크기로 충분한 이유

잔차는 0 근방에 집중된 저에너지·희소 신호다(오차는 구름 경계 등 일부 영역에 몰림). 이미지 전체의 분포를 담으려면 122.7M급 용량이 필요했지만, 오차 분포는 2.25M으로 담긴다. "디퓨전 하나 더"가 아니라 1/54 비용의 전문화된 소형 모델이라는 점이 실용적 차별점이다 (학습 30 epoch, 추론도 40스텝 × 소형망).

8.3 항등 하한 — 망칠 수 없게 설계된 두 번째 단계

보정은 가산(x̃ = ŷ + r̂)이고 출력 conv가 zero-init이므로, 학습 0스텝 시점의 보정기는 정확히 항등 함수다. 즉 두 번째 단계는 "아무것도 안 하는 것"에서 출발해 이득이 있는 방향으로만 이탈한다. 두 번째 생성 확산이 이미지를 처음부터 다시 그리면 이런 하한이 없다 — 베이스가 이미 맞춘 부분을 얼마든지 훼손할 수 있다.

8.4 앙상블 의미의 보존

확률성의 소재가 명확히 분리된다: 다양성은 Stage 1의 MC 샘플링에서만 나오고, Stage 2는 각 멤버에 결정적(시드 고정) 보정을 가한다. 그 결과 멤버 간 산포가 보존되어 앙상블 확률 지표(fair CRPS)가 훼손되지 않고 오히려 개선된다(t+4에서 −16%). 두 번째 생성 확산이 멤버를 재샘플링하면 Stage 1이 학습한 앙상블 분포가 뒤섞여 이 해석이 무너진다.

8.5 기존 캐스케이드 확산과의 위치 구분

확산 모델을 직렬로 쌓는 선행 사례(SR3, Cascaded Diffusion Models 류의 초해상 캐스케이드)는 각 스테이지가 저해상 출력을 조건으로 전체 이미지를 다시 생성하는 완전한 생성기다. 본 구조는 ① 동일 해상도에서 ② 잔차만 샘플링해 ③ 동결된 예측에 더하는 보정기라는 점에서 다르며, ④ 두 단계가 end-to-end가 아니라 파일 계약으로 분리되어 보정기만 독립적으로 교체·재학습할 수 있다(베이스 재학습 불필요).

  • FID는 표본 수·입력 폴더에 민감하므로(500장 캡 시 43→79 인플레이션) 비교 시 반드시 (폴더, n)을 명시.
